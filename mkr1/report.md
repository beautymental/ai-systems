# МКР №1. Як я покращив своє життя за допомогою AI
## AI-помічник для аналізу методичок
**Статус:** прототип підготовлено; реальні вимірювання та відео ще необхідно отримати.

| Поле | Опис |
|---|---|
| Проблема | Повторюваний аналіз методичок перед лабораторними роботами |
| Поточний процес | Прочитати матеріал, знайти варіант, виписати вимоги, скласти план і чекліст |
| Дані | Реальні навчальні PDF, TXT, Markdown |
| Рівень | 2 — RAG: пошук фрагментів документа перед генерацією |
| Метрика і ціль | Скоротити сумарний час аналізу та перевірки на 50%; не менше 90% правильних пунктів |
| Ризики / fallback | Звіряти план із методичкою; за недоступності моделі виконувати вручну |

## Архітектура
Документ → виділення тексту → фрагменти 1800 символів із перекриттям 300 → лексичне ранжування → до 6 фрагментів → Qwen2.5-1.5B-Instruct → план і чекліст → ручна перевірка → CSV. Інтерфейс Gradio, Python, Transformers, pypdf. Лексичний пошук обрано для простоти та швидкості; векторна база не потрібна для одного короткого документа.

## Ризики
| Ризик | Ймовірність / критичність | Дія |
|---|---|---|
| Вигадані команди | Середня / висока | Звіряти з оригіналом, не запускати неперевірене |
| Недоступність моделі | Середня / середня | Ручний аналіз |
| Сканований PDF | Середня / середня | OCR окремо або текстова версія |
| Пропуск потрібного фрагмента | Середня / висока | Перевірити показані фрагменти та повний документ |
| Конфіденційні дані | Низька / висока | Локальний запуск, не використовувати публічний Gradio для приватних файлів |

## Результати до / після
| Метрика | До | Після | Ціль |
|---|---|---|---|
| Середній час | Не виміряно | Не виміряно | −50% |
| Правильність пунктів | Не виміряно | Не виміряно | ≥90% |
| Вартість прогону | Без API | Без плати за токени; обчислення та електрика не оцінені | — |

Протокол: щонайменше три реальні методички. Спочатку вручну скласти план і заміряти час, потім виконати AI-аналіз, заміряти ручну перевірку та підрахувати правильні пункти. Зберегти CSV. Економія = 100 × (1 − сума часу AI і перевірки / сума ручного часу).

## Відповіді на 12 питань
1. Аналіз методичок та формування плану лабораторних.
2. Це повторювана навчальна задача, де важливо не пропустити вимоги.
3. Ручне читання, виписування та перевірка.
4. Прототип із пошуком фрагментів та генерацією плану.
5. Рівень 2 потрібен для доступу до конкретної методички, а не лише знань моделі.
6. Розглянуто один промпт із цілим документом, семантичний пошук та агента; лексичний пошук простіший.
7. Qwen2.5-1.5B-Instruct, Transformers, Python, Gradio, pypdf.
8. Потенційні проблеми: скани, пропущені фрагменти, галюцинації; фактичні помилки записати після тестів.
9. Надійність не встановлена; потрібна ручна перевірка.
10. Прототип автоматизує формування чернетки; реальний ефект ще не виміряно.
11. Економію часу визначити за CSV, без вигаданих чисел.
12. Додати семантичний пошук, OCR, перевірку цитат та підтримку довгих документів.
